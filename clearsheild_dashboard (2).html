Tobi connection

Tobi runs through a small private server that talks to DeepSeek for you. The DeepSeek key is stored only on that server (as DEEPSEEK_API_KEY). It is never put in this page.

What the server must provide

• POST /api/tobi/chat — receives your question and the selected website's check results, signed in with your ClearShield login.
• GET /api/tobi/health — says whether the server is ready.
• The server must allow this page's address: in its ALLOWED_ORIGINS setting.
The ready-to-use server is in the tobi-backend folder of the ZIP.

What Tobi sees

Tobi only receives your question, the website name and its check results. It never receives your password, email address or login details.

Tobi explains and guides. It does not change your website. ClearShield's checks are limited and cannot guarantee that a website is completely secure.
